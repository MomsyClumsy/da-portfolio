# Исследовательский анализ рынка общественного питания Москвы

## Задача

Инвесторы из фонда «Shut Up and Take My Money» планируют открыть заведение общественного питания
в Москве. Нужно провести исследовательский анализ рынка: изучить, какие форматы и районы наиболее
перспективны, как распределены заведения по категориям, сетевому статусу, ценовым сегментам
и рейтингам, и подготовить рекомендации по выбору формата и локации.

## Данные

Два датасета Практикума (`rest_info.csv` и `rest_price.csv`), объединённые по `id` в единый
датафрейм: **8406 строк, 13 столбцов**.

| Признак | Описание |
|---|---|
| `name` | Название заведения |
| `address` | Адрес |
| `district` | Административный округ Москвы |
| `category` | Категория: кафе, ресторан, кофейня, бар/паб, пиццерия, булочная, столовая, быстрое питание |
| `chain` | Сетевое заведение (1) или нет (0) |
| `hours` | Часы работы |
| `seats` | Количество посадочных мест |
| `rating` | Рейтинг заведения |
| `price` | Ценовая категория |
| `avg_bill` | Средний чек (строкой) |
| `middle_avg_bill` | Средний чек, число |
| `middle_coffee_cup` | Средняя стоимость чашки кофе |
| `is_24_7` | Круглосуточная работа (создан в ходе предобработки) |

Файлы данных лежат рядом с ноутбуком, скачивать ничего не нужно.

## Ход работы

1. **Загрузка данных** — объединение двух датасетов в единый датафрейм.
2. **Предобработка** — типы данных, анализ пропусков (до 93.6% в `middle_coffee_cup`), заглушки,
   поиск явных и неявных дубликатов, создание признака `is_24_7`.
3. **Исследовательский анализ** — 8 задач: категории, география, сетевые заведения, посадочные
   места, рейтинги, корреляции (`phik`), топ-15 сетей, средний чек по округам.
4. **Итоговый вывод и рекомендации** для заказчика.

## Ключевые результаты

**Структура рынка.** Преобладают кафе (2378, 28%), рестораны (2043, 24%) и кофейни (1413, 17%).
Несетевых заведений — 62% (5201) против 38% сетевых (3205). Наиболее «сетевые» категории:
булочные (61%), пиццерии (52%), кофейни (50%).

**География.** Лидирует ЦАО — 2242 заведения (в нём преобладают рестораны: 670), далее САО (900)
и ЮАО (892), минимум в СЗАО (409).

**Рейтинги.** Средний рейтинг по рынку — 4.23, различия между категориями невелики (в пределах ±0.2):

| Категория | Рейтинг |
|---|---|
| бар/паб | 4.39 |
| пиццерия | 4.30 |
| ресторан | 4.29 |
| кофейня | 4.28 |
| булочная | 4.27 |
| столовая | 4.21 |
| кафе | 4.12 |
| быстрое питание | 4.05 |

**Корреляции.** Сильных зависимостей рейтинга нет: максимальная связь с ценовой категорией
(φK = 0.28), далее округ (0.20) и категория (0.19). Количество посадочных мест на рейтинг
не влияет вовсе (0.00), круглосуточный режим — почти не влияет (0.15).

**Цены.** Медианный чек в ЦАО и ЗАО — 1000 руб., минимум в ЮВАО (537.5 руб.). Чек в ЦАО на 42.9%
выше, чем в остальных округах, но зависимость от удалённости не строго линейная: ЗАО при той же
медиане имеет более однородное распределение, тогда как в ЦАО сильнее выражен премиальный сегмент.

**Топ сетей:** Шоколадница (120 точек, 4.18), Домино'с Пицца (76, 4.17), Додо Пицца (74, 4.29),
One Price Coffee (71, 4.06).

## Рекомендации

- **Формат:** кофейни, пиццерии и кафе — доказали популярность и масштабируемость, особенно
  в сетевом формате.
- **Локация:** ЦАО даёт максимальный поток и чек, но высокую конкуренцию и стоимость входа;
  ЗАО — сопоставимый чек при более стабильной структуре рынка; САО и ЮАО — баланс спроса
  и конкуренции.
- **Ценовой сегмент:** средний и выше среднего (рейтинг 4.3–4.4). Дальнейший рост цены рейтинг
  не увеличивает, а низкий сегмент нестабилен по качеству.
- **Что не влияет на успех:** режим 24/7 и количество посадочных мест — по этим параметрам можно
  выбирать формат гибко.
