# Анализ клиентов сети фитнес-центров: прогноз оттока и сегментация

## Задача

Сеть фитнес-центров «Культурист-датасаентист» борется с оттоком клиентов. Клиент считается ушедшим,
если за последний месяц он ни разу не посетил зал. Нужно:

- научиться прогнозировать вероятность оттока на уровне следующего месяца;
- выделить типичные портреты клиентов (сегменты) и описать их свойства;
- определить признаки, сильнее всего влияющие на отток;
- сформулировать рекомендации по удержанию.

## Данные

Источник: `https://code.s3.yandex.net/datasets/gym_churn.csv` — 4000 клиентов, 14 признаков, пропусков нет.

| Признак | Описание |
|---|---|
| `gender` | Пол: 1 — женский, 0 — мужской |
| `Near_Location` | Проживание или работа в районе фитнес-центра |
| `Partner` | Сотрудник компании-партнёра клуба (корпоративная скидка) |
| `Promo_friends` | Запись по акции «Приведи друга» |
| `Phone` | Наличие контактного телефона |
| `Age` | Возраст |
| `Lifetime` | Время с момента первого обращения, месяцев |
| `Contract_period` | Длительность текущего абонемента (1, 3, 6 или 12 месяцев) |
| `Month_to_end_contract` | Срок до окончания абонемента, месяцев |
| `Group_visits` | Факт посещения групповых занятий |
| `Avg_class_frequency_total` | Средняя частота посещений в неделю за всё время |
| `Avg_class_frequency_current_month` | Средняя частота посещений в неделю за прошлый месяц |
| `Avg_additional_charges_total` | Выручка от прочих услуг клуба |
| `Churn` | Целевой признак — факт оттока |

## Ход работы

1. **EDA** — описательные статистики, сравнение средних в группах ушедших и оставшихся, матрица корреляций.
2. **Модель оттока** — бинарная классификация Random Forest, разбиение 80/20 со стратификацией.
3. **Кластеризация** — стандартизация, дендрограмма (`linkage`, метод Ward), K-Means на 5 кластеров.
4. **Выводы и рекомендации** по удержанию клиентов.

## Результаты

**Качество модели** (Random Forest, тестовая выборка):

| Метрика | Значение |
|---|---|
| Accuracy | 0.93 |
| Precision | 0.89 |
| Recall | 0.83 |

Модель верно классифицирует 93% клиентов; из отмеченных как «уйдёт» 89% уходят реально, при этом
заранее выявляются 83% реально ушедших.

**Портрет клиента группы риска:** молодой (~27 лет), недавно пришёл (стаж ~1 месяц против 4.7 у
оставшихся), короткий абонемент (~1.7 месяца против 5.7) и низкая частота посещений в последний
месяц (~1 раз в неделю против 2).

**Сегменты** (доля оттока по кластерам K-Means):

| Кластер | Доля оттока | Характеристика |
|---|---|---|
| 3 | 51.4% | Самый короткий абонемент, малый стаж, редкие посещения |
| 2 | 44.4% | Живут далеко от клуба, короткий абонемент, низкая активность |
| 1 | 26.8% | Средние значения по всем признакам |
| 4 | 6.8% | Самая высокая частота посещений, большой стаж |
| 0 | 2.8% | Длинный абонемент (~11 мес.), живут рядом, постоянные |

Доля оттока в целом по выборке — 26.5%, классы несбалансированы, поэтому одной accuracy для оценки
модели недостаточно.

## Рекомендации

1. **Удержание в первые месяцы.** Самый рисковый период — стаж менее двух месяцев. Welcome-программа
   с сопровождением тренера первые 4 недели.
2. **Мотивация к длинным абонементам.** Короткие абонементы связаны с высоким оттоком: бонус или
   скидка при переходе с месячного на 3- или 6-месячный.
3. **Стимулирование регулярности.** Падение частоты посещений — ранний сигнал риска: автоматическое
   предложение клиенту, не посещавшему зал 10+ дней.
4. **Работа с удалённым сегментом.** Кластер 2 требует отдельного исследования потребностей и
   тестирования мер, снижающих влияние расстояния (например, удобное расписание групповых занятий).

Эффективность всех перечисленных мер стоит проверять экспериментами.
