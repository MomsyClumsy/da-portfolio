# Ключевые бизнес-метрики в Саранске (май — июнь 2021)

Дашборд в Yandex DataLens по сервису доставки еды: динамика ключевых продуктовых метрик
и рекомендации для роста сервиса.

**→ [Открыть живой дашборд](https://datalens.yandex/1fw4wty8do7yl?tab=mW)**

## Состав дашборда

**Вкладка «Данные»** — 7 чартов:

| Чарт | Метрика |
|---|---|
| DAU | Ежедневная активная аудитория |
| Средний чек по месяцам | Средний чек заказа |
| CR | Конверсия из визита в заказ |
| RR первой недели после установки приложения | Удержание по дням 0–7 |
| RR первой недели по месяцам | Удержание в разрезе когорт |
| LTV блюд | Выручка в разрезе блюд |
| LTV ресторанов | Выручка в разрезе ресторанов |

**Вкладка «Аналитическая записка»** — разбор каждой метрики с трендом, выводами и гипотезами
о причинах. Полный текст: [analytical_note.md](analytical_note.md).

## Ключевые выводы

- **DAU** нестабилен: всплеск в начале июня (до 80+) сменяется снижением к концу месяца (~30–40).
- **CR** колеблется в диапазоне ~18–43% без выраженного тренда — проблемы в воронке.
- **Средний чек** вырос с 135,88 (май) до 147,66 (июнь), примерно на 8,7%.
- **Удержание** проседает резко: 100% в день 0 → ~14% в день 1 → ~4% к 7 дню. Это главная
  проблема продукта.
- **LTV** концентрируется в ресторанах с разнообразным меню: топ-3 — Гурманское Наслаждение
  (170 479), Гастрономический Шторм (164 508), Шоколадный Рай (74 392).

Приоритет рекомендаций — удержание: бонусы и пуши для мотивации повторных заказов.

## Данные

Источник — PostgreSQL, датасет `rest`: события пользователей, заказы, справочники ресторанов
и блюд, рекламные бюджеты. Данные учебные, доступ к базе не публичный.

## Файл экспорта

[`dashboard_export.json`](dashboard_export.json) — выгрузка дашборда из DataLens (подключение,
датасет, 7 чартов и раскладка). Позволяет импортировать дашборд в свой инстанс DataLens
и посмотреть, как он устроен, независимо от публичной ссылки.

Импорт: в рабочей книге DataLens → **Создать** → **Импортировать** → выбрать файл. После импорта
нужно указать собственные реквизиты подключения к базе — исходная БД в выгрузку не входит.
